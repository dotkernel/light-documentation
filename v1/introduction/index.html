Dotkernel Light

Summary

A one-paragraph technical overview of Dotkernel Light, plus the badges tracking its build, quality and license status.

Details

Dotkernel Light is a PSR-15 compliant application (skeleton) using Mezzio microframework and Laminas components. It's designed as a minimal project to generate a simple website, like a presentation site.

Read on to find out more about the application:

  • A technical overview to understand technical requirements and included packages
  • A step-by-step installation guide to get you up and running in minutes
  • Detailed how-tos for managing the dynamic content

Check out our demo.

FAQ

Q: What is Dotkernel Light? A: A PSR-15 compliant application skeleton built on Mezzio and Laminas components, designed as a minimal project for generating a simple website such as a presentation site.

Q: Where can I see it running? A: On the live demo.

Q: Where do I start if I want to install it? A: With the installation guide, starting at Getting started.
